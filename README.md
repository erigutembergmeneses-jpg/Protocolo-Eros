# O Vazio que Se Instala

> “Este era um refúgio. Agora, é a resistência.”

**O Vazio que Se Instala** é um espaço digital colaborativo para compartilhar cicatrizes emocionais, histórias de perda, memórias apagadas e afetos dissidentes. Inspirado por experiências de ruptura e reconstrução, o projeto transforma dor em narrativa, e narrativa em revolução.

---

## 🌐 Acesse o site

🔗 [www.ovazioqueseseinstala.com](https://exemplo.com) *(substitua pelo seu domínio real)*

## ✨ Funcionalidades

- Fórum melancólico para envio de relatos
- Galeria de vozes da dissidência
- Manifesto interativo sobre afeto e resistência
- Design minimalista e poético com foco na experiência emocional
